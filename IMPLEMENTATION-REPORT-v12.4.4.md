# Marveltonez Website v12.4.4 — Individual Songwriter Profile Pages

Status: READY FOR REVIEW
Date: 10 September 2026

## Scope

This release adds two canonical individual writer identity pages without changing the existing protected catalogue or access architecture.

- `/mike-blake/`
- `/mike-shannon/`

## Mike Blake

- Public identity: English songwriter, producer and composer based in Austria.
- Relationship: one half of The Marveltonez songwriting partnership with Mike Shannon.
- Focus: Marveltonez catalogue for recording artists and industry opportunities, including selected sync opportunities.
- Existing approved writer portrait reused.
- BOOTS is included only on Mike Blake's selected-work list as a separate project.

## Mike Shannon

- Public identity: UK songwriter, composer and musician.
- Relationship: one half of The Marveltonez songwriting partnership with Mike Blake.
- Focus: strictly the Marveltonez catalogue and artist/industry opportunities.
- Existing approved writer portrait reused.
- Mike Shannon LinkedIn retained as a secondary profile route.

## Search and identity work

Both pages include unique titles/descriptions, canonical URLs, social metadata and Schema.org Person structured data. The homepage Organization schema now links each writer to the corresponding canonical profile URL. Both pages are present in `sitemap.xml`.

## Existing-page changes

- Industry writer cards now link to the individual profiles and use the approved identity descriptors.
- Homepage writer cards now link to the profiles and use the approved identity descriptors.

## Explicit non-changes

No Professional Catalogue data, Cloudflare Access settings, catalogue rendering logic, audio, consent behaviour, analytics architecture or song copy was changed.
